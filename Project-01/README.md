# Project 01 — SQL Data Analysis with Hospital Database

## Overview

This project focuses on practical SQL data analysis using the **Hospital** relational database in **Microsoft SQL Server**.

The project demonstrates how SQL can be used to retrieve, filter, transform, update, and analyze patient data to answer a variety of real-world data-related questions.

## Database

**Database:** Hospital
**Platform:** Microsoft SQL Server
**Language:** T-SQL

## Skills Demonstrated

* Data retrieval using `SELECT`
* Filtering data with `WHERE`
* Handling missing values with `IS NULL`
* Pattern matching with `LIKE`
* Range filtering with `BETWEEN`
* Filtering multiple values with `IN`
* Combining conditions with `AND`
* String manipulation using `CONCAT`
* Data modification using `UPDATE`
* Data aggregation using `COUNT`
* Date-based filtering
* Working with relational database tables

## Project Tasks

The project includes several SQL queries designed to analyze patient information, including:

* Identifying patients based on gender
* Finding patients with missing allergy information
* Searching for patients by first-name patterns
* Updating missing allergy values
* Filtering patients based on weight
* Creating a full name from first and last names
* Counting patients born in a specific year
* Retrieving patients using specific patient IDs
* Identifying patients based on height and weight conditions
