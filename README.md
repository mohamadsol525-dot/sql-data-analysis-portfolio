# Project 03 — Relational Data Analysis with SQL JOINs

## Overview

This project focuses on analyzing relational data using **SQL JOIN operations** in the **Northwind** database.

The project demonstrates how data can be combined from multiple related tables to retrieve meaningful information about customers, orders, products, employees, categories, and suppliers.

## Database

**Database:** Northwind
**Platform:** Microsoft SQL Server
**Language:** T-SQL

## Skills Demonstrated

* Relational database analysis
* `JOIN`
* `LEFT JOIN`
* Joining multiple tables
* Working with primary and foreign key relationships
* Filtering data with `WHERE`
* Grouping data with `GROUP BY`
* Retrieving related records across tables
* Identifying records without matching relationships
* Multi-table data analysis

## Project Scope

The project contains several SQL queries focused on relationships between the following tables:

* `Customers`
* `Orders`
* `Order Details`
* `Products`
* `Categories`
* `Suppliers`
* `Employees`

The queries demonstrate how these tables can be connected to analyze different aspects of the database.

## Key Analysis Tasks

The project includes analysis such as:

* Retrieving customer orders
* Comparing customers with and without orders
* Identifying customers who have not placed orders
* Connecting products with their categories
* Connecting products with suppliers and categories
* Identifying products without a matching category
* Retrieving products associated with specific orders
* Combining information from multiple related tables
